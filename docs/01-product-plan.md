# 01 产品方案

## 定位

SPORTSIX 小程序做三件事：品牌和产品介绍、活动通知、会员沉淀。不做商城，没有价格、购物车和支付。

「分段补给计算」是特色功能：用户选项目、时长、体重等，得到整场带几支、每支什么时候吃。它在底部导航占一个独立入口，保存结果需要先成为会员，以此带动注册。

## 信息架构

底部导航四项，顺序固定：

| 序 | 名称 | 页面 | 说明 |
|---|---|---|---|
| 1 | 介绍 | 首页 | 品牌、卖点、产品线、背书、品牌影片 |
| 2 | 补给 | 分段补给计算 | 凸起的黄绿圆形按钮，始终高亮 |
| 3 | 活动 | 活动列表 | 即将开始 / 往期 |
| 4 | 我的 | 我的 | 未注册和已注册两种状态，同一个页面 |

二级页面三个：能量胶详情、能量胶PRO 详情、活动详情。增效凝胶、CLEAR SHOT、REVITAL DRINK 目前没有中文详情资料，只在产品线里出现，不可点击。

## 产品详情模块顺序

两款详情的骨架相同，中段内容各自不同：

1. 首屏：款名、标题、口味（能量胶可切换）
2. 四个数字
3. 直白卖点：一句话定位加三条卖点（`keyPoints`）
4. 各自的成分与原理模块（`sections` 里食用方法之前的各块：能量胶六块、能量胶PRO 五块）
5. 场景推荐：三个使用场景，底部按钮跳分段补给计算（`scenes`）
6. 食用方法（`sections` 的最后部分：能量胶的 `howTo`，能量胶PRO 的 `guide` 和 `qa`）
7. 营养成分表
8. 产品速选对比：两款并排八行，当前产品一列加粗，底部链接到另一款（`products.json#compare`）
9. 成为会员

第 3、5、8 项的内容来自《SPORTSIX产品介绍文档（教练版）》，取舍见 `docs/04-open-items.md`。

## 首页模块顺序

1. 首屏：字标、WIN YOUR DAY、「缓释超低渗，慢慢来才更快」、品牌一句话、「韩国原装进口」标签、两支能量胶包装
2. 三个数字：60+ / 250 / 5，下面接两张产品入口卡（能量胶、能量胶PRO，点开进详情；设计稿里没有，开发时补的，文案取自产品线）
3. 三个卖点卡片：缓释、超低渗、HBCD
4. 分段补给计算入口
5. 全周期运动产品线：运动前、运动中、运动后，沿一条竖线排开
6. 快慢双碳：配速对比曲线
7. 三个规格：1115 KJ/100g、45mg、45g
8. Informed-Sport 认证
9. 合作伙伴和赛事：可左滑的赛事照片卡
10. 厂房照片和品牌介绍、六大运动核心价值
11. 品牌影片
12. 成为会员

顺序的依据：前半页讲卖点和工具，后半页放背书和情感内容，最后落到注册。

## 分段补给计算

输入八项，分三组：

| 组 | 输入 | 取值 | 默认 |
|---|---|---|---|
| 这场运动 | 项目 | 路跑、越野、骑行、徒步、登山、滑雪（两行三列） | 路跑 |
| | 强度 | 轻松训练、高强度训练、比赛，选中的一档下面有一句说明（徒步、登山、滑雪时隐藏） | 比赛 |
| | 预计时长 | 0:30 到 10:00，按钮每次 ±15 分钟或 ±1 小时 | 4:00 |
| 你的情况 | 体重 | 40 到 110kg，每次 ±5 | 65 |
| | 咖啡因 | 正常、敏感 | 正常 |
| | 用胶经验 | 用过、第一次 | 用过 |
| 当天 | 出发时间 | 上午、下午、晚上 | 上午 |
| | 天气 | 常温、高温、低温、雨天（低温、雨天为开发时补充，只影响说明文字，不改支数） | 常温 |

切换项目时，预计时长重置为该项目的默认值：路跑 4:00、越野 8:00、骑行 3:00、徒步 5:00、登山 6:00、滑雪 4:00。

输出：

- 这场带几支，其中能量胶几支、能量胶PRO 几支
- 总碳水（g）、咖啡因（mg）、能量（千卡）
- 一条时间轴，每支胶一个点：能量胶是黄绿实心点，PRO 是白色空心点
- 每支的时刻，五列排布的格子：能量胶黄绿底，PRO 深色描边
- 「为什么这样排」：最多六条说明
- 结果为 0 支时，显示「这次不用带胶」

任一输入变化后立即重算，不设「计算」按钮。公式见 `docs/03-fuel-formula.md`，实现见 `reference/fuel-plan.js`。

「保存到我的」：未注册时跳到注册；已注册时保存本次输入和结果，在「我的」里显示为「我的补给计划」。第一版只保存最近一份。

## 会员

- 注册只取微信身份和手机号，不收集其他信息。
- 权益是常规项：优先报名、试用装、积分、抽奖。具体规则未定，页面上的一句话说明是暂写的。
- 昵称：会员页点名字可以填和改。输入框是微信的昵称键盘，键盘上方可以一键选用微信昵称（微信不再允许小程序直接读取昵称，只能由用户自己选）。没填时显示「SPORTSIX 会员」。
- 会员编号按注册先后发，6 位数字，从 100001 起。编号规则定下来之前注册的会员，下次进入小程序时补发。
- 积分：注册送 500；会员卡上写「后续可用于兑换和参与活动」，点积分进积分页（当前积分、用途说明、积分记录）。兑换和活动的具体规则未定。规则定下来之前注册的会员，下次进入小程序时补送一次。
- 注册按钮的文案是「手机号快捷登录」：平台审核不允许手机号验证的前置页面出现「微信」字样。

## 通知

小程序自身只能发一次性订阅消息：用户每点一次授权，换一条通知。所以：

- 单场活动的提醒走订阅消息：用户点「提醒我」时调起授权，报名开放时发一条。
- 持续的通知走社群：活动详情和「我的」里都有加群入口。群的形式（企业微信群、客服二维码）未定。
- 不能用「订阅送积分」这类做法，平台按诱导订阅处理。

## 开发时补充的约定

- 全站文案做过一轮统一（量词用「支」、能量单位用「千卡」、款名只用「能量胶」「能量胶PRO」、入口说「登录 / 加入」不说「注册」），并改掉了几处互相矛盾的地方，逐条见这次改动的 PR 说明。
- 款名：普通版叫「能量胶BASIC」，和「能量胶PRO」对应，地方小时简写 BASIC、PRO。「能量胶」只作品类的统称。别的品牌的胶写作「其他胶」。
- 能量胶PRO 的食用指南按补给计算的节奏写：赛前 30 分钟 1 支，比赛中每 20 分钟 1 支，最后 15 分钟不再补。
- 首页「六大运动核心价值」单独成一块（大数字 6、标题、六张带编号的卡片），内容是原来品牌介绍下面的六项。
- 首页首屏有一个 Informed Sport 认证标，点了滚到认证说明。标志文件取自 Informed Sport 官网，随包（`miniprogram/assets/icons/informed-sport-*.png`），原图在 `assets/logo/`。用标的授权范围待品牌方确认。
- 转发给朋友：除会员页、积分页外都可以。分享到朋友圈：只有首页和两个产品页（朋友圈里打开的是单页模式，不能跳转、没有底部导航、云开发不能用）。

## 运营后台

只有管理员（云数据库里会员记录上有 `admin: true`）能看到，入口在「我的」页最下面。设计稿里没有，页面沿用现有的头部、卡片和按钮样式，文字在 `reference/content/admin.json`。

- 活动：列表（已上架、未上架、已结束）、新建、编辑、上架、下架。
- 公告：标题、内容、开关。保存后每位用户下次打开小程序时弹一次。
- 积分：按手机号或会员编号找会员，加减积分并写原因，会员在积分页能看到。

主动给用户发消息只有两条路：公告弹窗（用户打开小程序时才看到），和报名开放时的订阅消息（只发给点过「提醒我」的人）。微信不允许小程序主动群发。

运营后台还有一个电脑端的网页版（`web-admin/index.html`），功能相同，放在云开发的静态网站上。登录靠小程序里取的一次性登录码。部署步骤和安全上的做法见 `cloudfunctions/README.md` 的「电脑端后台」。
