# 02 设计规范

设计稿宽 390px。小程序里换算成 rpx：`rpx = px × 750 ÷ 390`（1px ≈ 1.923rpx）。`design/tokens.json` 和 `design/tokens.wxss` 是下面内容的机器可读版本。

## 颜色

| 名称 | 色值 | 用途 |
|---|---|---|
| 深蓝 | `#010439` | 首屏和深色分区的底色；黄绿底上的文字 |
| 标题蓝 | `#061A70` | 数字、小标题、会员卡底色 |
| 黄绿 | `#C2E541` | 主按钮、弧线、标签、能量胶的标记色 |
| 底灰 | `#F5F5F5` | 卡片底色、浅色分区 |
| 分割线 | `#E6E6E7` | |
| 正文 | `#14141E` | |
| 次要文字 | `#5E6170` | 说明、未选中 |
| 深色底上的次要文字 | `#C9CEE8` | |
| 深色底上的线 | `#2A3373` | |

规则：

- 黄绿只做底色和线条，不做白底上的文字（对比度不够）。黄绿底上的字用深蓝。
- 屏幕色值取自现有电商详情页。印刷专色是 Pantone 2766 C 和 Pantone 2297 C。

## 字体

- 中文：系统字体。设计稿用 Noto Sans SC 绘制，字重 400 / 500 / 700 / 900。不要加载中文字体文件，体积太大。
- 数字和英文：Barlow Condensed，斜体，字重 700 / 800，呼应字标的倾斜。字体文件在 `assets/fonts/`，开源授权（OFL）。用 `wx.loadFontFace` 加载，加载失败时回退到系统字体。
- 中文不要套斜体。数字和中文混排时，只给数字套 Barlow Condensed。

## 布局

- 页面左右边距 20px。
- 分区上边距 36 到 40px。
- 卡片内边距 16px；卡片之间 10 到 14px。
- 圆角：小块 10、色块 12、卡片 14 到 16、大面板 18；按钮和标签用全圆角。
- 触控目标不小于 44px。主按钮高 52px。
- 底部导航高 64px，中间的「补给」按钮直径 48px、向上凸出 18px、带 3px 白色描边。真机上要加底部安全区。

## 图形

| 图形 | 文件 | 用法 |
|---|---|---|
| 字标 | `assets/logo/sportsix-wordmark-*.svg` | 深色底用白，浅色底用深蓝；不变形、不改色 |
| 口号 | `assets/logo/win-your-day-*.svg` | |
| 头像 | `assets/logo/avatar-1024.png` | 暂定稿，需品牌方确认 |
| 黄绿弧线 | `assets/graphics/*-arc.svg` | 配深蓝网格底；外圈一层模糊的光晕 |
| 首屏细线 | `assets/graphics/hero-track-lines.svg` | 白色 16% 透明度 |
| 海拔线 | `assets/graphics/ridge-line.svg` | 赛事类活动 |
| 图表 | `assets/graphics/chart-*.svg`、`radar-*.svg` | 配速、缓释、渗透压、吸收对比、原料 |
| 图标 | `assets/icons/<名称>-<颜色>.svg` | 2px 线性，24px 网格，五种颜色 |

深蓝网格底：深蓝底色上叠两组 1px 白线（5% 透明度），格子 26px。实现见 `tokens.wxss` 的 `.sx-grid-bg`。

斜切标签：左右各切 8px 的平行四边形，角度随字标。实现见 `.sx-slant`。

时间顺序用「竖线加圆点」表达：4px 黄绿线，24px 圆点（深蓝实心、3px 黄绿描边）。产品线、HBCD 流程、食用指南、补给时间轴都用这一套。

## 照片

- 厂房、赛事等背书照片保留原色。
- 场景图（网图）压成深蓝单色，融进底色：照片去色、提高对比，以 50% 到 85% 透明度叠在深蓝底上。设计稿用 `filter: grayscale(1) contrast(1.15)` 加 `mix-blend-mode: screen`。如果目标渲染环境不支持混合模式，改为预先处理好的图片。
- 文字压在照片上时，照片一侧加一层深蓝渐变保证可读。
- 网图来源和授权见 `assets/photos/web/SOURCES.md`。

## 动效

| 名称 | 做法 | 用在哪里 |
|---|---|---|
| 悬浮 | 上下 12px，5 到 6 秒，往复 | 首屏和注册页的产品包装 |
| 光晕 | 透明度 0.38 到 0.8，2.8 秒，往复 | 弧线外圈 |
| 绘制 | 从左到右画出，1.6 到 1.8 秒 | 曲线、海拔线 |
| 生长 | 从基线长出，0.9 秒 | 柱形图、横条 |
| 入场 | 上移 14px 淡入，0.7 秒，逐项错开 0.1 到 0.15 秒 | 首屏文字、卡片 |
| 弹出 | 从 92% 放大淡入，0.3 秒 | 切换口味、补给格子 |
| 按压 | 缩到 96% | 所有按钮 |

- 进入视口时再触发绘制、生长和入场；设计稿里是页面加载时触发。
- 用户开启「减少动态效果」时全部关闭。

## 小程序里的实现提示

以下几点动手前请对照微信官方文档确认：

- WXML 里没有 `svg` 标签。图形以图片方式使用（`image` 组件或背景图）。需要动画的曲线，可以用一层遮罩从左到右展开来模拟绘制，或者用 canvas。
- 弧线的光晕在 SVG 里是高斯模糊滤镜。作为图片使用时滤镜仍然有效；如果目标机型显示异常，导出成 PNG。
- 自定义底部导航：`app.json` 的 `tabBar.custom` 设为 `true`，在根目录放 `custom-tab-bar` 组件。
- 单个包不超过 2M。图片、视频、字体放 CDN，包里只留图标这类小文件。
